Face & Voice Emotion Deception Detector

A multimodal emotion analysis system built with Python that analyzes uploaded videos using facial expressions and voice emotions to identify possible emotional mismatches.

🚀 Features
🎭 Facial Emotion Detection – Analyzes facial expressions from uploaded videos.
🎙️ Voice Emotion Detection – Analyzes emotions from the audio in the video.
🧠 Multimodal Analysis – Combines facial and voice emotion results.
⚠️ Emotion Mismatch Detection – Identifies differences between facial and vocal emotions.
🎥 Video Upload & Analysis – Upload a recorded video and analyze its emotional content.
🖥️ Gradio Interface – Provides a simple and interactive user interface.
🛠️ Technologies

Python • Gradio • OpenCV • Computer Vision • NLP • Machine Learning • Audio Processing

🎯 Objective

The project aims to combine facial and voice emotion analysis to provide a better understanding of emotional behavior and detect possible inconsistencies between a person's expressions and speech.

Note: An emotion mismatch does not necessarily indicate deception. It can occur due to stress, context, personality, or other factors.
